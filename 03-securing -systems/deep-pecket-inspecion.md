# Deep Packet Inspection

## O que é?

*Deep Packet Inspection (DPI)* é uma técnica usada para **analisar o conteúdo dos pacotes de dados** que passam por uma rede.

Diferente de apenas verificar informações básicas, como IP e porta, o DPI pode analisar mais profundamente os dados que estão dentro dos pacotes.

## Como funciona?

Um dispositivo de rede, como um *firewall* ou *proxy*, pode analisar os pacotes que passam por ele.

Com isso, pode identificar determinados tipos de tráfego e, dependendo das regras configuradas, **permitir, bloquear ou modificar** esse tráfego.

## Exemplos

Uma empresa pode usar *Deep Packet Inspection* para analisar o tráfego da sua rede e bloquear determinados tipos de conteúdo ou conexões.

## O que eu aprendi?

Aprendi que o *Deep Packet Inspection* permite analisar os pacotes de uma forma mais profunda, podendo ser usado por ferramentas de segurança para controlar o tráfego de uma rede.

## Observações

Quando o tráfego está **criptografado**, como acontece com `HTTPS`, a capacidade de analisar o conteúdo dentro dos pacotes é limitada, porque os dados estão protegidos por criptografia.
