# IP Address

## O que é?

*IP Address* significa *Internet Protocol Address*.

É um **endereço usado para identificar um dispositivo em uma rede**, permitindo que os dados saibam para onde devem ser enviados.

Podemos pensar no IP como o **endereço de um dispositivo na rede**.

## IP Público

O **IP público** é o endereço usado para identificar uma rede ou dispositivo na internet.

É o endereço que pode ser visto por servidores e outros dispositivos na internet.

Por exemplo, quando acessamos um site, o servidor consegue identificar o IP público de onde veio a requisição.

## IP Privado

O **IP privado** é usado dentro de uma **rede local**, como a rede Wi-Fi de uma casa, empresa ou escola.

Ele permite que os dispositivos dentro dessa rede se comuniquem entre si.

Um exemplo seria:

`192.168.1.10`

Esse endereço pode ser usado pelo seu computador dentro da rede local, mas não é o endereço usado diretamente para identificar seu computador na internet.

## Diferença

De forma simples:

`IP privado → usado dentro da rede local`

`IP público → usado para comunicação com a internet`

## O que eu aprendi?

Aprendi que um dispositivo pode ter um IP privado dentro da sua rede e a rede pode ter um IP público usado para se comunicar com a internet.
