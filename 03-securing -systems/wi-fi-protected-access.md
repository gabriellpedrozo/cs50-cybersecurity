# Wi-Fi Protected Access

## O que é?

*Wi-Fi Protected Access (WPA)* é uma tecnologia usada para proteger redes Wi-Fi.

Ela utiliza **criptografia** para proteger os dados que são enviados entre um dispositivo e o ponto de acesso (*Access Point*).

## Como funciona?

Quando um dispositivo se conecta a uma rede Wi-Fi protegida, os dados enviados entre o dispositivo e o *Access Point* são criptografados.

Isso dificulta que alguém que esteja observando o tráfego da rede consiga entender as informações que estão sendo transmitidas.

## Exemplos

Quando conectamos o celular ou computador em uma rede Wi-Fi protegida por WPA, a comunicação entre o dispositivo e o *Access Point* é protegida por criptografia.

## O que eu aprendi?

Aprendi que o WPA ajuda a proteger uma rede Wi-Fi usando criptografia, principalmente na comunicação entre o dispositivo e o *Access Point*.

## Observações

O WPA protege a comunicação entre o dispositivo e o *Access Point*, mas isso não significa que toda comunicação na internet esteja protegida. Protocolos como `HTTPS` também são importantes para proteger os dados até o servidor.
