# Deletion

## O que é?

Deletion é o processo de excluir arquivos de um computador.

Porém, excluir um arquivo não significa necessariamente que todos os seus dados foram removidos do dispositivo.

## Como funciona?

Quando um arquivo é excluído, o sistema operacional pode simplesmente deixar de indicar onde aquele arquivo está armazenado.

O espaço pode então ser utilizado para armazenar novos dados, que podem sobrescrever os dados antigos.

## Exemplos

Ao excluir um arquivo, como:

`documento.txt`

O sistema pode apenas remover a referência ao arquivo, enquanto partes dos dados antigos ainda permanecem no armazenamento.

## O que eu aprendi?

Aprendi que excluir um arquivo não garante que todos os seus dados tenham sido completamente removidos.

Também aprendi que existe a **secure deletion**, que busca remover os rastros dos arquivos apagados sobrescrevendo seus dados.

## Observações

A exclusão comum pode deixar rastros de arquivos antigos no armazenamento.

Na secure deletion, os dados restantes são sobrescritos com zeros, uns ou uma sequência aleatória de zeros e uns.
