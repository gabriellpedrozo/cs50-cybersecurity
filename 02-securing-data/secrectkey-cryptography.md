# Secret Key e Cryptography

## O que é?

Cryptography é o uso de técnicas para proteger informações.

Secret key é uma chave utilizada na criptografia simétrica para proteger e recuperar informações.

## Como funciona?

Na criptografia simétrica, a mesma chave secreta é utilizada para criptografar e descriptografar os dados.

A mensagem original é transformada em uma mensagem criptografada usando a chave. Para recuperar a mensagem original, é necessário utilizar a chave correta.

## Exemplos

Mensagem original:

`Olá, tudo bem?`

Após a criptografia:

`X7#kP9@2...`

Com a chave secreta correta, a mensagem pode ser descriptografada e recuperada.

## O que eu aprendi?

Aprendi que a criptografia pode ser usada para proteger informações contra pessoas que não possuem a chave necessária.

Também aprendi que, na criptografia simétrica, a mesma chave é utilizada para criptografar e descriptografar os dados.

## Observações

A chave secreta precisa ser protegida, pois quem tiver acesso a ela pode conseguir descriptografar os dados protegidos por essa chave.

Criptografia é diferente de hashing: a criptografia permite recuperar o conteúdo original utilizando uma chave, enquanto o hashing transforma os dados em um hash.
