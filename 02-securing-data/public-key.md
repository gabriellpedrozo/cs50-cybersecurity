# Public-Key Cryptography

## O que é?

Public-Key Cryptography, ou criptografia de chave pública, é uma forma de criptografia assimétrica que permite proteger informações usando duas chaves: uma chave pública e uma chave secreta.

## Como funciona?

O remetente utiliza a chave pública do destinatário junto com a mensagem original para gerar um texto criptografado.

O destinatário utiliza sua chave secreta junto com o texto criptografado para recuperar a mensagem original.

## Exemplos

Mensagem original:

`Olá, tudo bem?`

A mensagem é criptografada usando a chave pública do destinatário.

Depois, o destinatário usa sua chave secreta para descriptografar a mensagem e recuperar o conteúdo original.

## O que eu aprendi?

Aprendi que a criptografia de chave pública permite que duas pessoas protejam informações mesmo sem terem estabelecido previamente uma chave secreta compartilhada.

Também aprendi que ela utiliza uma chave pública para criptografar e uma chave secreta para descriptografar.

## Observações

Public-Key Cryptography também é chamada de criptografia assimétrica.

A chave pública pode ser compartilhada, enquanto a chave secreta deve ser protegida.
