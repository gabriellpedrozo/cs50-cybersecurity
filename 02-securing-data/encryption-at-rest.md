# Encryption at Rest

## O que é?

Encryption at Rest é a criptografia dos dados enquanto eles estão armazenados em um dispositivo.

O objetivo é proteger os dados caso o dispositivo seja perdido, roubado ou acessado por alguém sem autorização.

## Como funciona?

Os dados armazenados no dispositivo são criptografados.

Para acessar esses dados, é necessário utilizar a chave ou mecanismo de autenticação adequado para descriptografá-los.

## Exemplos

Um notebook possui arquivos armazenados no disco.

Com a criptografia de disco, os arquivos são mantidos de forma criptografada no armazenamento.

Se o notebook for roubado, uma pessoa que tentar acessar diretamente o disco não terá acesso aos dados sem a forma correta de descriptografia.

## O que eu aprendi?

Aprendi que a criptografia em repouso protege os dados enquanto eles estão armazenados.

Também aprendi que a criptografia de disco completo (**Full-Disk Encryption**) pode criptografar todo o conteúdo do disco.

## Observações

Encryption at Rest também é chamada de **Full-Disk Encryption** quando todo o conteúdo do disco é criptografado.

Ela é diferente de **Encryption in Transit**, que protege os dados enquanto eles estão sendo transmitidos por uma rede.
